ルール・仕様説明

【基本ルール】

・毎ターン提示される「BPM指定」に合う楽曲カードを出し合い、相手より先に目標スコア（魂ゲージ）に到達した方の勝利です。
・BPMが合わない場合は、「出さずにパス」するか、「手札を1枚捨ててパス（交換）」することができます。
・先攻/後攻は「カードのBPMが高い方」が先攻となります。BPMが同じ場合はコンボ数が多い方が先攻です。
・試合終了後も部屋は解散されず、ロビーへ戻って続けて対戦できます。

【系統（ジャンル）の相性】

カードの系統には相性があり、有利な場合は獲得スコアが「1.2倍」、不利な場合は「0.8倍」になります。
・🔴物量(1) は 🟣局所難(4) に有利
・🟣局所難(4) は 🔵技術(2) に有利
・🔵技術(2) は 🔴物量(1) に有利
※🟢総合(3) と 🌀特殊(5) は相性の影響を受けません。

【段位カード（キラキラカード）】

過去や現在の段位道場でボスを務めた曲は、強力なバフを持っています。
・赤枠: 全良確率+10%
・銀枠: 全良確率+15%
・金枠: 全良確率+20%
・プラチナ枠: 全良確率+25%
・虹枠: 全良確率+30%
・★キラキラボーナス: 全良・フルコンボ・クリアでスコアが増える際の倍率が＋0.2倍に強化されます。
・さらに「オート」で演奏した場合も、基礎倍率が「1.0倍」から「1.4倍」に強化されます。

【サブカード（アイテム）の新仕様】

・サブカードは1ターンにつき最大1枚のみ使用できます。
・サブカードの補充は2ターンに1度行われます。

【新アイテム＆注目アイテム】

・★4 公式マイバチ（蒼/朱/山吹）: それぞれ技術(2)、総合(3)、物量(1)のカードを出した時のみ使用可能。全良確率+15%、フルコン確率+15%！
・★4 かんぺき: フルコン・全良時の倍率がそれぞれ+2.0倍になる超絶強化。ただし失敗時の倍率は-0.7倍に悪化！
・★4 代行: そのターンだけ相手が獲得したポイントを自分にもそのまま加算！
・★4 ドロン: 自分のゲージが相手に3ターン見えなくなり（数値とゲージのたまり具合が完全隠蔽）、さらに相手のオート演奏を3ターン封印！
・★3 あべこべ: 自分の手札2枚を選択し、相手の手札2枚（ランダム）と交換！
・★1/2/3 演奏速度×1.1 / ×1.2 / ×1.3: スコア増加量をそれぞれ1.1倍、1.2倍、1.3倍にブースト！
・★1 バチお先生: フルコンボ確率を+14%上昇！

【★5 段位道場の特殊仕様】

アイテム「段位道場」は、自分の場に出した曲が『画像の段位3曲目』である場合のみ使用できる超強力カードです。
使用した場合、BPMにかかわらず**強制的に先攻**となります。
さらにコンボ数が「段位の3曲合計」に上書きされ、通常のルーレットが『段位専用の超絶ルーレット』に変化します。
・赤(十段): 全良3%(x1.5) / 金合格10%(x1.3) / 赤合格25%(x1.2) / 不合格62%(x-0.3)
・銀(名人等): 全良2%(x2.2) / 金合格6%(x1.7) / 赤合格10%(x1.4) / 不合格82%(x-0.2)
・達人(金/虹): 全良1%(x10.2) / 赤合格9%(x3.2) / 不合格90%(x-0.1)
