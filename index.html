ルール・仕様説明

【基本ルール】

・毎ターン提示される「BPM指定」に合う楽曲カードを出し合い、相手より先に目標スコア（魂ゲージ）に到達した方の勝利です。
・BPMが合わない場合は、「出さずにパス」するか、「手札を1枚捨ててパス（交換）」することができます。
・先攻/後攻は「カードのBPMが高い方」が先攻となります。BPMが同じ場合はコンボ数が多い方が先攻です。
・試合終了後も部屋は解散されず、ロビーへ戻って続けて対戦できます。

【系統（ジャンル）の相性】

カードの系統には相性があり、有利な場合は獲得スコアが「1.2倍」、不利な場合は「0.8倍」になります。
・🔴物量(1) は 🟣局所難(4) に有利
・🟣局所難(4) は 🔵技術(2) に有利
・🔵技術(2) は 🔴物量(1) に有利
※🟢総合(3) と 🌀特殊(5) は相性の影響を受けません。

【段位カード（キラキラカード）】

過去や現在の段位道場でボスを務めた曲は、強力なバフを持っています。
・オート演奏成功時の倍率: 虹枠: 1.5倍 / プラチナ枠: 1.4倍 / 金枠: 1.3倍 / 銀枠: 1.2倍 / 赤枠: 1.1倍 (通常枠: 1.0倍)
・全良成功確率ボーナス: 虹枠: +30% / プラチナ枠: +25% / 金枠: +20% / 銀枠: +15% / 赤枠: +10%
※全良確率が増加した分、フルコンボ・クリア・失敗の確率は元の比率を保ったまま均等に調整（減少）されます（失敗確率が大きく下がる強力な効果です）。
・★キラキラボーナス: 全良・フルコンボ・クリアでスコアが増える際の倍率が＋0.2倍に強化されます。

【レートシステム（CPU対戦限定）】

・レートはCPU戦でのみ上下します。
・レート階級は C- → C → C+ → B- → B → B+ → A- → A → A+ → S → S+ → X の全12段階です。
・レート帯ごとにフォントとバッジがゴージャスに変化します（C帯: 銅 / B帯: 銀 / A帯: 金 / S帯: プラチナ / X帯: 虹）。
・昇格・降格の仕組み: 各帯とも0〜100ptで推移します。100ptを超えると次のレート帯の30ptからスタートし、逆に0ptを下回ると1つ下のレート帯の70ptに降格します（最下層のC-は0ptでストップ）。
・最高峰の「X帯」はポイント上限が無制限となります！
・ふつうモード（基準）でのポイント変動：
　・C帯 (C-, C, C+): 勝利 +30 pt / 敗北 -15 pt
　・B帯 (B-, B, B+): 勝利 +20 pt / 敗北 -12 pt
　・A帯 (A-, A, A+): 勝利 +15 pt / 敗北 -9 pt
　・S帯 (S): 勝利 +10 pt / 敗北 -7 pt
　・S+帯 (S+): 勝利 +7 pt / 敗北 -7 pt
　・X帯 (X): 勝利 +3 pt / 敗北 -5 pt
・難易度による倍率補正（小数第1位で四捨五入）：
　・かんたんモード: × 2/3
　・むずかしいモード: × 4/3
・⚠️ 試合中断時のペナルティ: 対戦途中で「中断」した場合、敗北扱いとなります。レートは現在の階級に応じたポイントがマイナスされ（A帯なら-9ptなど、モード補正適用）、0pt未満になると降格します（中断した試合は敗北として通算戦績に加算）。※中断時はランクは変動しません。
・🥋 練習モード: メニュー画面で「練習モード (レート保護)」をONにすると、レートが一切変動しなくなります。また、練習モードでの対戦は勝敗・中断問わず通算戦績に一切加算されません（安全にお試し対戦可能）。

【ランクシステム（CPU戦・オンライン戦共通）】

・ランクはCPU戦・オンラインルーム戦・練習戦でポイントが加算されます。
・ランクは「1」から始まり、最大「30」まで昇格可能です（ランク30到達後はポイントが無制限に蓄積）。
・次のランクに昇格するために必要なポイントは、初項3、公差2の等差数列（ランク1→2は3pt、2→3は5pt、3→4は7pt...、ランクR→R+1は 2R+1 pt）で増えていきます。
・試合終了時の獲得ポイント：
　・かんたんモード: 勝利 +4 pt / 敗北 +1 pt
　・ふつうモード: 勝利 +6 pt / 敗北 +2 pt
　・むずかしいモード: 勝利 +8 pt / 敗北 +3 pt
・※試合を中断した場合はランクポイントの変動はありません（維持）。

【難易度帯別（全18段階）の確率分布・倍率・期待値一覧】

・F（最も簡単）からSS（最難関）まで18段階の等差設定です（※個人差Fは存在しないため除外）。
・1000コンボのカードを想定した場合、オート演奏では1000点増えますが、じぶんで演奏するとハイリスク・ハイリターンになります。
・じぶんで演奏した時の期待値は、F帯で約1020点、難易度が上がるにつれて少しずつ高くなり、SS帯では約1122点になります。
・全良とフルコンボの差が大きく設定されており、全良達成時のボーナスが極めて強力です。
・失敗時の減点倍率はF帯の-1.0倍からSS帯の-0.5倍まで段階的に緩和されます。
