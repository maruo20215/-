ルール・仕様説明

【基本ルール】

・毎ターン提示される「BPM指定」に合う楽曲カードを出し合い、相手より先に目標スコア（魂ゲージ）に到達した方の勝利です。
・BPMが合わない場合は、「出さずにパス」するか、「手札を1枚捨ててパス（交換）」することができます。
・先攻/後攻は「カードのBPMが高い方」が先攻となります。BPMが同じ場合はコンボ数が多い方が先攻です。

【系統（ジャンル）の相性】

カードの系統には相性があり、有利な場合は獲得スコアが「1.2倍」、不利な場合は「0.8倍」になります。
・🔴物量(1) は 🟣局所難(4) に有利
・🟣局所難(4) は 🔵技術(2) に有利
・🔵技術(2) は 🔴物量(1) に有利
※🟢総合(3) と 🌀特殊(5) は相性の影響を受けません。

【段位カード（キラキラカード）】

過去や現在の段位道場でボスを務めた曲は、強力なバフを持っています。
・赤枠: 全良確率+10%
・銀枠: 全良確率+15%
・金枠: 全良確率+20%
・プラチナ枠: 全良確率+25%
・虹枠: 全良確率+30%
※さらに、これらのカードを「オート」で演奏した場合、基礎倍率が「1.0倍」から「1.2倍」に強化されます。

【サブカード（アイテム）の確率分布】

山札が構築される際、以下の確率でアイテムが抽選されます。
・★1 (白): 33.3% （カービィ、バチお先生）
・★2 (緑): 26.6% （HS2.0、でたらめ、きまぐれ）
・★3 (青): 19.9% （HS3.0、けいた、よすが、演奏スキップ、爆弾音符）
・★4 (紫): 13.3% （ドロン、復活連打、まきな、代行、双打、HS4.0）
・★5 (金): 6.6% （段位道場）

【★5 段位道場の特殊仕様】

アイテム「段位道場」は、自分の場に出した曲が『画像の段位3曲目』である場合のみ使用できる超強力カードです。
使用した場合、BPMにかかわらず**強制的に先攻**となります。
さらにコンボ数が「段位の3曲合計」に上書きされ、通常のルーレットが『段位専用の超絶ルーレット』に変化します（他のバフ・デバフは一切無効化されます）。
・赤(十段): 全良3%(x1.3) / 金合格10%(x1.1) / 赤合格25%(x1.0) / 不合格62%(x-0.3)
・銀(名人等): 全良2%(x2.0) / 金合格6%(x1.5) / 赤合格10%(x1.2) / 不合格82%(x-0.2)
・達人(金/虹): 全良1%(x10.0) / 赤合格9%(x3.0) / 不合格90%(x-0.1)
